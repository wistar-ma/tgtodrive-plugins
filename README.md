# TgtoDrive 插件集合

TgtoDrive「实用工具 → 我的插件」的插件仓库（符合官方插件市场格式）。

## 插件列表

| 插件 | 说明 | 版本 |
| --- | --- | --- |
| [整理后自动分享](plugins/organize-share/plugin.py) | 影视整理完成后自动生成 123 云盘分享链接并发送到 Telegram 群 + pan1.me 论坛 | 1.0.18 |

## 安装方式

### 方式 A：直接导入（推荐先试）

1. 打开 TgtoDrive → 实用工具 → 我的插件 → 导入插件。
2. 选择本仓库的单个文件 `organize-share.py`（或从 Release 下载）。
3. 确认信任 → 打开 → 填写参数 → 运行。

### 方式 B：插件市场（可一键更新）

1. TgtoDrive → 实用工具 → 我的插件 → 插件市场 → 来源设置。
2. 新增来源：`wistar-ma/tgtodrive-plugins`，分支 `main`，目录 `plugins.json`。
3. 保存并刷新 → 在市场中找到「整理后自动分享」→ 确认信任并安装。

## 整理后自动分享（organize-share）

影视整理完成后，扫描 123 云盘整理目标目录树，识别带 `{tmdb}` 的标题文件夹，
为「新增」的剧/电影生成 123 云盘分享链接，并发送到指定 Telegram 群（可选同步发帖到 pan1.me 论坛社区）。

### 特点

- **只发新增**：首次运行只 seed 基线（约 16,481 个历史标题，不发群），之后仅处理新整理的剧/电影，不会刷屏。
- **完全可配置**：目标群、提取码、有效期、整理根目录、快速扫描年份阈值、全量间隔、媒体分类过滤、消息模板，全部可在插件表单里改。
- **pan1.me 论坛发帖**：自带「社区发帖」开关，开启后自动在 pan1.me 建主题帖——链接放「回复可见」（用论坛 tt_read 插件的 `[ttreply]` 标记）或「登录可见」字段，按电影/电视剧/动漫/综艺自动选版块，画质标签按真实画质（4K/1080p…）自动选，标题自动去重（同一标题不重复发帖）。凭据自动读取同容器 `user.env` 里的论坛地址与 Cookie。
- **零侵入**：只读同容器的 `/app/db/user.env` 凭据，不碰 TgtoDrive 源码。

### 使用步骤

1. 把机器人 `@OracleTgto123_Bot` 拉进目标群并在群里发一条消息。
2. 插件里「运行模式 = 获取群ID」跑一次，复制返回的 `chat_id` 填进「目标 TG 群 chat_id」并保存设置。
3. 想同步发论坛：开「社区发帖」开关，版块留 `auto`（按分类自动选），链接字段默认「回复可见」。
4. 自动扫描：我的插件 → 定时执行 → 选本插件 → 模式=`scan` → cron `*/3 * * * *`。

### 可配置项

| 参数 | 说明 |
| --- | --- |
| 目标 TG 群 chat_id | 分享发送到的群 ID，留空则只建链不发送 |
| 运行模式 | scan / 全量扫描 / 回填基线 / 试运行 / 获取群ID |
| 分享提取码 | 123 分享提取码 |
| 分享有效期 | 0=永久 / 1 / 7 / 30 天 |
| 整理目标根目录 ID | 123 整理目标根，默认读 ENV_123_ORGANIZE_TARGET_PID |
| 快速扫描年份阈值 | 低于该年份不纳入快速扫描 |
| 全量扫描间隔轮次 | 每 N 次快速扫描做一次全量 |
| 媒体分类 include / exclude | 正则过滤一级媒体分类 |
| 社区发帖（pan1.me） | 总开关，开启后自动在论坛建主题帖 |
| 论坛版块 fid | 留空或 auto 按分类自动选；也可手动指定 fid |
| 链接字段 | http_url=回复可见（`[ttreply]`）/ vod_url=登录可见（`[ttlogin]`）/ message=正文 |
| 论坛标题去重 | 同一标题已在论坛发过则跳过 |
| 是否发送 TG 群 | 总开关 |
| 消息模板 | 变量 `{title}` `{year_block}` `{category}` `{url}` `{pwd}` `{name}` |

## 更新日志

- **1.0.18**：修复记录页在 `http://`（非安全上下文）下**「复制」按钮无效**——此时 `navigator.clipboard` 不可用，改为回退 `textarea + document.execCommand("copy")`，失败时再弹出可手动复制的输入框；同时把「帖子链接」列里没有帖子的行由 `—` 改成明确的「未发帖」（悬停提示说明是社区开关未开）。
- **1.0.17**：把记录页**做成可点击链接**——宿主机 Caddy 只读托管 `records.html`（仅绑内网 IP，公网不可达，且只暴露该文件、不含 `state.json`），插件设置页与每次运行结果都给出「打开查询记录页」链接；新增输入项「记录页访问地址」可自定义。
- **1.0.16**：**修复插件在插件列表里消失**。原因是清单 `ui` 的 alert 组件用了非法的 `style.tone`（`info`），平台校验不通过会把整份清单判为损坏并丢弃该插件（日志：`无法读取插件 organize-share 的配置: 组件 style.tone 无效`，调度侧显示「插件配置损坏，请重新导入」）。现已改用合法取值（`default/primary/success/warning/danger/muted`），并新增 `_sanitize_ui()` 对清单与运行结果里的 `style.tone/align/size/variant` 做归一化兜底，避免同类问题再次让插件“隐身”。
- **1.0.15**：把记录页路径显式暴露出来——插件设置页新增一条说明，且每次运行结果的第一条提示即「查询记录页已更新：&lt;路径&gt;」。记录页是**文件**（不是网页链接）：容器内 `/app/db/toolbox/plugins/organize-share/data/records.html`，随 `/app/db` 绑定挂载，宿主机路径为 `&lt;TgtoDrive&gt;/db/toolbox/plugins/organize-share/data/records.html`；浏览器打开即可搜索/筛选/导出。
- **1.0.14**：新增「一标题一链接一帖子」——同一标题只保留一条分享链接、一个社区帖。已分享标题内容有更新（新增集数/规格变化）时：① 复用原分享链接向 TG 群发「更新通知」（不重新建链）；② 原地更新该标题已有的社区帖（`?post-update-{pid}.htm`，改标题/正文/标签，不新建帖子），查不到原帖时才补发。检测用低成本信号（123 目录聚合体积/更新时间）先筛疑似，再按内容签名 `_sig`（视频文件名+体积哈希）确认，避免时间戳抖动误报；老记录首轮只建基线。新增两个开关「标题更新时发 TG 通知」「标题更新时原地更新社区帖」（默认开）。
- **1.0.13**：运行结束时在插件 `data/` 目录自动生成自包含记录页 `records.html`（内嵌全部已建链记录，含搜索/分类筛选/状态筛选/点列排序/复制链接/导出 CSV），经 `/app/db` 绑定挂载可在容器外直接打开查询。
