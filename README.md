# TgtoDrive 插件集合

TgtoDrive「实用工具 → 我的插件」的插件仓库（符合官方插件市场格式）。

## 插件列表

| 插件 | 说明 | 版本 |
| --- | --- | --- |
| [整理后自动分享](plugins/organize-share/plugin.py) | 影视整理完成后自动生成 123 云盘分享链接并发送到 Telegram 群/社区 | 1.0.0 |

## 安装方式

### 方式 A：直接导入（推荐先试）

1. 打开 TgtoDrive → 实用工具 → 我的插件 → 导入插件。
2. 选择本仓库的单个文件 `organize-share.py`（或从 Release 下载）。
3. 确认信任 → 打开 → 填写参数 → 运行。

### 方式 B：插件市场（可一键更新）

1. TgtoDrive → 实用工具 → 我的插件 → 插件市场 → 来源设置。
2. 新增来源：`wistar-ma/tgtodrive-plugins`，分支 `main`，目录 `plugins.json`。
3. 保存并刷新 → 在市场中找到「整理后自动分享」→ 确认信任并安装。

## 整理后自动分享（organize-share）

影视整理完成后，扫描 123 云盘整理目标目录树，识别带 `{tmdb}` 的标题文件夹，
为「新增」的剧/电影生成 123 云盘分享链接，并发送到指定 Telegram 群（可选同步到社区/频道）。

### 特点

- **只发新增**：首次运行只 seed 基线（约 16,481 个历史标题，不发群），之后仅处理新整理的剧/电影，不会刷屏。
- **完全可配置**：目标群、提取码、有效期、整理根目录、快速扫描年份阈值、全量间隔、媒体分类过滤、消息模板，全部可在插件表单里改。
- **社区推送开关**：自带「同步发送到社区/频道」开关，关掉就只发 TG 群。
- **零侵入**：只读同容器的 `/app/db/user.env` 凭据，不碰 TgtoDrive 源码。

### 使用步骤

1. 把机器人 `@OracleTgto123_Bot` 拉进目标群并在群里发一条消息。
2. 插件里「运行模式 = 获取群ID」跑一次，复制返回的 `chat_id` 填进「目标 TG 群 chat_id」并保存设置。
3. 想用社区推送：开「同步发送到社区/频道」开关，填「社区/频道 chat_id」（`-100` 开头），机器人需是该社区/频道成员且有发消息权限。
4. 自动扫描：我的插件 → 定时执行 → 选本插件 → 模式=`scan` → cron `*/3 * * * *`。

### 可配置项

| 参数 | 说明 |
| --- | --- |
| 目标 TG 群 chat_id | 分享发送到的群 ID，留空则只建链不发送 |
| 运行模式 | scan / 全量扫描 / 回填基线 / 试运行 / 获取群ID |
| 分享提取码 | 123 分享提取码 |
| 分享有效期 | 0=永久 / 1 / 7 / 30 天 |
| 整理目标根目录 ID | 123 整理目标根，默认读 ENV_123_ORGANIZE_TARGET_PID |
| 快速扫描年份阈值 | 低于该年份不纳入快速扫描 |
| 全量扫描间隔轮次 | 每 N 次快速扫描做一次全量 |
| 媒体分类 include / exclude | 正则过滤一级媒体分类 |
| 同步发送到社区/频道 | 总开关 |
| 社区/频道 chat_id | `-100` 开头 |
| 是否发送 TG 群 | 总开关 |
| 消息模板 | 变量 `{title}` `{year_block}` `{category}` `{url}` `{pwd}` `{name}` |
